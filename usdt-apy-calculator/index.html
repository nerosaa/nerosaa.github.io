How it works

  • APR is the nominal yearly rate; APY is the effective yearly rate after compounding. APY = (1 + APR/n)n − 1, and APR = n × ((1 + APY)1/n − 1), where n is compounding periods per year.
  • Rate per period: APR/n if you enter an APR, or (1 + APY)1/n − 1 if you enter an APY. Without top-ups, final = start × (1 + rate per period)periods.
  • Time: 1 year = 365 days = 12 months; a month is 365/12 ≈ 30.42 days. A leftover partial period at the end is compounded fractionally, so results stay consistent with the yearly rate.
  • Top-ups are added at the end of each month and start compounding from that moment.
