USDT to IDR calculator

Convert between USDT and Indonesian rupiah (IDR). The page loads an approximate live rate when it opens; you can always overwrite it with the rate you are actually offered.

Default 18,000 is only a rough placeholder (Oct 2026) until the live rate loads. Real quotes vary — enter the rate you are actually offered.

How it works

IDR = USDT × rate. USDT = IDR ÷ rate. Type in either box and the other updates. The live rate comes from CoinGecko's public USDT price (fallback: the open.er-api.com USD/IDR reference rate). If an exchange or P2P quote differs, the difference is the spread or fee you are paying. If the live rate cannot load, just type a rate manually.
