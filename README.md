# nerosaa.github.io

Free client-side tools for crypto freelancers. Each page links to Getly products (USDT).

- `/usdt-network-fees/` — TRC20 / BEP20 / ERC20 fee comparison
- `/usdt-qr/` — USDT wallet QR (TRC20 / BEP20 / ERC20)
- `/usdt-erc20-gas-fee-calculator/` — ERC20 USDT gas fee calculator
- `/usdt-to-aed-calculator/` — USDT ⇄ AED converter (manual rate)
- `/invoice-number-generator/` — sequential invoice numbers
